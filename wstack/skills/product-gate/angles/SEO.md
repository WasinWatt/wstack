# SEO

Question: will the changed page still be found for what people search, and does it break nothing that search engines already index?

- Title and description: present, specific to the page, in the page's language, within the length the repo's other pages use.
- The page keeps one H1 and headings in order. A heading that people search for (a feature name, a question) stays a heading.
- A changed URL or slug has a redirect from the old one, and every internal link to it is updated. A missing redirect → `blocker`.
- Structured data the repo emits (FAQ, breadcrumbs) still matches the visible text.
- New images have alt text in the page's language.
